# Sistema da Clínica — versão de demonstração

Protótipo do sistema de gestão da clínica da Dra. Marcela Corrêa (Cirurgia Plástica) e da Dra. Rafaela Tridapalli (Prevenção e Nutrologia).

- Todos os pacientes, valores e datas são **exemplos**.
- O que for cadastrado fica salvo apenas no navegador de quem está usando.
- Para voltar ao estado inicial: menu lateral → "Restaurar dados de exemplo".

Publicação: GitHub Pages, branch `main`, pasta raiz (`/`). O arquivo de entrada é `index.html`.
